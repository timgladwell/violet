# Ontario Menopause Clinic website

The marketing site for Ontario Menopause Clinic, published at
<https://ontariomenopauseclinic.ca>: a static Hugo site hosted on Cloudflare
Pages, and the top of the funnel into online booking through Avaros.

**Scope:** the site, its build and release tooling, and the record of the
Cloudflare and GitHub configuration it depends on
([`docs/current-state/`](docs/current-state/)). The business context and the
principles every change is held to are in [CLAUDE.md](CLAUDE.md#principles).

## Getting started

- [CLAUDE.md](CLAUDE.md#development-scripts) — the development scripts
  (`./dev-server.sh`, `./validate.sh`) and the environment variables.
- [CONTRIBUTING.md](CONTRIBUTING.md) — where each kind of information lives.
- [Architecture decisions](docs/adr/) and [runbooks](docs/runbooks.md).
