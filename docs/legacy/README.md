# Legacy documents

Frozen. These predate the convention in [CONTRIBUTING.md](../../CONTRIBUTING.md)
and are kept only as a reference for how the project got here. They are not
updated, are out of date in places, and are not a source of truth for anything:
decisions now live in issues and [ADRs](../adr/), the principles every change
is held to in [CLAUDE.md](../../CLAUDE.md#principles), and the site's content
in `site/`.

Paths inside them (`@docs/...`) are as they were before the files moved here.

| File | What it was |

| `website_design.md` | The original site requirements, content notes and reference sites |
| `decision_log.md` | Decision table kept before decisions moved to issues |
| `investigation_notes.md` | Research behind the early technology choices (Hugo, Cloudflare Pages) |
| `competitive_analysis_and_recommendations.md` | Claude-authored analysis of similar sites, behind the original site structure |
| `website_content_draft.md` | Claude-authored worksheet for gathering Andrea's notes on content and structure |
| `Website Content Draft.md` | Andrea's notes in that worksheet |
| `website_aesthetic_design_notes.md` | Each aesthetic design iteration and Andrea's feedback on it |
| `*_inspo.png` | Inspiration images referenced by the aesthetic notes |
| `seo_optimization_notes.md` | Early keyword research |
| `quiz_design.md` | Original spec for the "Is HRT right for me?" quiz, since built |
